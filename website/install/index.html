Install

Install trueflow

Use the one-line installer to detect the supported build, verify its checksum, and place trueflow in ~/.local/bin by default.

Current binary support: Apple Silicon macOS. More targets can be added once the initial packaging and release flow is stable.

Quick install

The installer script auto-detects the supported platform and fetches the matching versioned artifact from /download/.

Latest release

curl -fsSL https://trueflow.dev/install.sh | sh

Pinned version

curl -fsSL https://trueflow.dev/install.sh | sh -s -- --version v0.1.0

The script currently supports Apple Silicon macOS and verifies the downloaded checksum before installing.

Manual download

If you prefer not to use the installer script, download the archive and checksum directly.

  • trueflow-v0.1.0-aarch64-apple-darwin.tar.gz
  • trueflow-v0.1.0-SHA256SUMS.txt 
curl -fsSLO https://trueflow.dev/download/trueflow-v0.1.0-aarch64-apple-darwin.tar.gz
curl -fsSLO https://trueflow.dev/download/trueflow-v0.1.0-SHA256SUMS.txt
shasum -a 256 -c trueflow-v0.1.0-SHA256SUMS.txt
tar -xzf trueflow-v0.1.0-aarch64-apple-darwin.tar.gz
install -m 0755 trueflow ~/.local/bin/trueflow

These URLs go live when the first signed-off binary release is published.
